# Шаблон для Яндекс Директ

Универсальный навык Codex для создания и первичного заполнения базы знаний клиентского проекта по Яндекс Директу.

Текущая версия набора: **1.6.0**. Техническое имя: `client-project-init`.

## Состав

```text
skills/client-project-init/
├── SKILL.md
├── agents/openai.yaml
├── assets/project/
│   ├── AGENTS.md
│   └── Agent/
│       ├── CLIENT.md
│       ├── AUDIENCE.md
│       ├── ADVERTISING.md
│       ├── CAMPAIGN_RULES.md
│       ├── ANALYTICS.md
│       ├── STATUS.md
│       ├── DECISIONS.md
│       ├── EXPERIMENTS.md
│       ├── CHANGELOG.md
│       ├── inbox/INPUTS.md
│       └── campaigns/RSYA_BLOCKED_PLACEMENTS.txt
└── references/

    └── brief-map.md
```

При инициализации дополнительно создаются папки данных, кампаний, отчётов и архива внутри Agent/.

## Использование в Codex

После установки навыка открой папку клиента и напиши:

```text
Создай файлы проекта из моего шаблона для Яндекс Директ.
```

Явный вызов: `$client-project-init`. Сразу можно передать бриф; недостающие сведения уточняются небольшими блоками вопросов. Повторный вызов не должен перезаписывать заполненные документы или сбрасывать историю.

Для установки из будущего репозитория укажи Codex ссылку на репозиторий и путь навыка `skills/client-project-init`. Для приватного репозитория потребуется доступ к нему. Репозиторий: https://github.com/Bleffucio/yandex-direct-template. Первый выпуск: v1.2.0.

## Версии и обновления

Основной источник шаблона — https://github.com/Bleffucio/yandex-direct-template, каталог skills/client-project-init. Установленный навык является локальной копией выбранной версии.

Порядок обновления:

1. Основные шаблоны хранятся в репозитории, установленный навык — локальная рабочая копия для использования в Codex.
2. Перед обновлением получить изменения из репозитория и проверить несохранённые локальные правки.
3. В отдельной ветке изменить файлы навыка и шаблонов; сохранить остальные правила и исключить клиентские сведения.
4. Увеличить версию в SKILL.md и assets/project/AGENTS.md, описать изменения в references/template-history.md, обновить указанную здесь версию.
5. Проверить навык и содержание шаблонов, сохранить коммит с понятным описанием. Отправить изменения в репозиторий и объединить через pull request в рамках разрешения пользователя.
6. Отмечать готовые выпуски тегами вида v1.1.0; при необходимости создавать GitHub Release. Существующие теги не передвигать.
7. Перед установкой новой версии сохранить резервную копию локального навыка, проверить локальные изменения, затем установить нужную версию и проверить файлы.

GitHub не синхронизирует установленный навык и клиентские проекты автоматически. Обновление существующего клиента — отдельная операция: резервная копия документов, добавление нужных полей и правил с сохранением значений и всей истории, запись фактических изменений в журнал.

## Содержимое репозитория

Хранить только универсальные шаблоны, инструкции и историю их версий. Заполненные клиентские файлы, выгрузки, доступы и локальные резервные копии в этот репозиторий не входят.


## Вопросы первичного брифа

Все 48 вопросов детального брифа распределены по тематическим файлам. [Карта вопросов](skills/client-project-init/references/brief-map.md) показывает исходные ячейки и назначение каждого вопроса. Аудитория ведётся в AUDIENCE.md и дополняется в ходе работы. Исходный Excel и заполненные ответы клиентов в репозиторий не входят.

## Правила новых кампаний

[CAMPAIGN_RULES.md](skills/client-project-init/assets/project/Agent/CAMPAIGN_RULES.md) содержит базовые настройки Поиска, обязательное оформление ключевых фраз, последовательность создания исключаемых аудиторий и вопросы по недостающим параметрам. Бюджет по умолчанию — 15 000 руб. в неделю на каждую кампанию без НДС; максимальный CPC не задаётся без требования ТЗ. Исключаются пользователи с 2 и более отказными визитами из Директа либо с 4 и более визитами из Директа за последние 90 дней, а также достигшие любой цели фактического лида из любого источника за последние 360 дней. Для РСЯ используется максимум конверсий с оплатой за клики, только недельный бюджет (по умолчанию 7 000 руб. без НДС на кампанию) и согласованные ценности целей; минус-фразы не добавляются, ключевые слова — без операторов. Включён снимок базового списка площадок (221 значение из Google-таблицы на 2026-11-25) и процедура проверки актуального источника перед созданием кампании. Для подготовки текстов используется адаптированный ad-creative из этого репозитория.
