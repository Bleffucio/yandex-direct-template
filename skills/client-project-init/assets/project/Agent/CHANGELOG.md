## Записи

## Формат записи
- ID: CH-001 для первого изменения, далее последовательно.
- Дата изменения: YYYY-MM-DD или «Неизвестна»; время и часовой пояс — если известны.
- Дата внесения записи: если отличается от даты события или дата события неизвестна.
- Объект: система, кабинет, тип, название, ID / путь файла.
- Изменение: конкретные действия; было → стало, если известно. Для массовых изменений — полный перечень или ссылка на него.
- Причина: явно указанная причина и источник либо «Не указана».
- Исполнитель: если известен.
- Источник и проверка: чем подтверждено; изменения со слов пользователя помечай явно.
- Связанное решение / эксперимент: если есть.

Историю не стирай. Откат фиксируй отдельно. Неизвестные значения не восстанавливай догадками. Планы и согласования без выполнения храни в других файлах. Не создавай записи о каждом пополнении самого журнала и техническом обновлении STATUS.md.
