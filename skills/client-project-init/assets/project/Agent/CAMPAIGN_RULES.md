# Правила создания новых кампаний

Обновлено: {{DATE}}.
Статус: базовые правила Поиска и РСЯ согласованы пользователем. Для каждой кампании по проекту определяются кабинет, счётчики, цели и география; для РСЯ также согласуются ценности выбранных целей. Для текстов комбинаторных объявлений используется адаптированный навык ad-creative.

Правила относятся к новым кампаниям Яндекс Директа. Индивидуальные согласованные требования проекта имеют приоритет над базовыми значениями. Изменения действующих кампаний по этому файлу автоматически не выполняются. Создание и запуск — отдельные действия в пределах задания пользователя.

## Данные и подготовка до создания кампании

1. Прочитать [CLIENT.md](CLIENT.md), [AUDIENCE.md](AUDIENCE.md), [ADVERTISING.md](ADVERTISING.md), [ANALYTICS.md](ANALYTICS.md) и относящиеся к задаче решения.
2. Определить точный кабинет, тип кампании (общая или брендовая), сайт, географию, счётчик Метрики и согласованные ключевые цели с ID. Для исключения лидов использовать только цели фактической заявки, звонка или письма. Клики по телефону и почте не считать фактическим обращением и не включать в эти ключевые цели.
3. Если счётчик или ключевые цели неизвестны либо нет нужного доступа, запросить их до создания аудиторий и кампании. Не создавать новые цели Метрики вместо выбора существующих без отдельного задания.
4. До создания кампании создать необходимые аудитории / условия, описанные ниже, либо проверить и использовать существующие эквивалентные объекты. Не создавать дубликаты только из-за названия. Проверить логику, счётчик, сроки и доступность; сохранить ID и условия в AUDIENCE.md и ANALYTICS.md. Это рабочая последовательность пользователя; завершение сбора аудитории и её фактический объём проверяются отдельно.
5. Применять согласованные ниже значения бюджета и окон аудиторий без повторного запроса. Недостающие сведения конкретного проекта запросить до соответствующих настроек. Проверить доступность настроек и корректность реализации условий в актуальном интерфейсе или API; неподдерживаемую настройку не отмечать выполненной и не заменять приближённым условием.

## Поиск — настройки кампании

| Параметр | Базовое правило пользователя |
|---|---|
| Места размещения | «Продвижение в Поисковой выдаче» и «Динамические места на Поиске» |
| Стратегия | «Максимум кликов» по согласованному бюджету |
| Бюджет | Недельный, отдельно для каждой кампании, без НДС. Если сумма не указана — 15 000 руб. в неделю на каждую кампанию |
| Максимальный CPC | Ограничение не устанавливать, если пользователь явно не потребовал его в ТЗ |
| Метрика | Подходящие к сайту и проекту счётчики и согласованные целевые действия |
| Расписание | По умолчанию круглосуточно; часовой пояс фиксировать по проекту |
| Возраст | Любой пол, младше 18 лет: корректировка −100% |
| Персонализация объявлений | Отключена |
| Мониторинг сайта | Включён |
| Приоритизация объявлений | «По фразе, наиболее близкой к запросу» |

Другие места размещения не подключать без согласования. Не путать «Максимум кликов» с отдельной стратегией «Максимум кликов с ручными ставками». Максимальный CPC по умолчанию не ограничивать; значение задавать только по прямому требованию в ТЗ.

### Исключаемые аудитории (Поиск и РСЯ)

| Аудитория | Условие включения пользователя | Скользящее окно | Корректировка на кампанию |
|---|---|---|---|
| Отказы с рекламы Яндекс Директа | Не менее 2 отказных визитов из Яндекс Директа; оба признака (источник и отказ) относятся к каждому из учитываемых визитов | Последние 90 дней | −100% |
| Более 3 рекламных визитов | Как минимум 4 визита из Яндекс Директа | Последние 90 дней | −100% |
| Достигшие ключевых целей | Достигнута хотя бы 1 из согласованных ключевых целей фактического обращения (лида); источник визита любой | Последние 360 дней | −100% |

Для первых двух аудиторий учитывать только рекламу Яндекс Директа, без других рекламных систем и органического трафика. «2 отказных визита» означает порог не менее 2, а не ровно 2. «Более 3» означает не менее 4 рекламных визитов.

Проверять именно количество подходящих визитов пользователя в заданном окне. Не подменять «2 отказных визита из Директа» сочетанием «2 всех визита и хотя бы один отказ» или «2 отказа из любых источников и хотя бы один визит из Директа». Не подменять «4 визита из Директа» сочетанием «4 всех визита и хотя бы один рекламный». Рекламные клики и визиты не считать взаимозаменяемыми.

Для аудитории лидов цели объединять логикой **ИЛИ / выполнена хотя бы одна**. Ограничения по источнику нет: исключаются также лиды из органики, прямых заходов и других источников. Основание пользователя: повторно привлекать уже обратившихся не требуется. Это правило исключения не переопределяет отдельный учёт лидов, договоров и продаж в аналитике.

Клики по телефону, email или открытие почтовой программы сами по себе не являются фактическим лидом. Для исключения использовать согласованные goal_id, которые означают фактическую заявку, состоявшийся звонок или отправленное обращение. Если доступны только кликовые цели, запросить подходящие ключевые цели, а не подставлять кликовые.

Окна 90 и 360 дней — скользящие: пользователь исключается, пока выполняется соответствующее условие за последние дни. Не превращать это в бессрочный запрет, фиксированный архивный сегмент или дополнительный срок поверх указанного окна. Перед применением проверить, что выбранный способ формирования и обновления аудитории воспроизводит эти условия.

Сегмент для корректировки и техническое условие его использования в Директе могут быть разными объектами. Не предполагать обязательное использование сервиса «Яндекс Аудитории»: выбирать доступный способ на основе согласованного счётчика, целей и условий. Уровень корректировок — кампания; проверять, нет ли групповых настроек, меняющих итоговое применение.

### Параметры URL (Поиск и РСЯ)

В поле «Параметры URL» использовать следующую строку без добавления начального `?`:

```text
utm_source=ya&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={gbid}|{ad_id}|{region_name}|{device_type}|source-{source}&utm_term={keyword}|{match_type}|{matched_keyword}|pid-{phrase_id}|position_type-{position_type}|position-{position}
```

Сохранять `utm_source=ya` и остальные значения как указано пользователем. Проверять конечные ссылки, существующую разметку и перенаправления, чтобы не создавать конфликтующих дубликатов UTM. Значения динамических параметров оценивать с учётом фактического условия показа; отсутствие значения само по себе не означает ошибку разметки.

## Поиск — настройки групп

### География

Географию задавать на уровне групп по техническому заданию. Если отдельного задания нет — по согласованной желаемой географии рекламирования проекта. Если она не указана, запросить. Настройка расширенного геотаргетинга пользователем пока не определена: не выбирать её произвольно.

### Ключевые фразы

Пользовательское правило оформления: каждое слово фразы, кроме предлогов, заключать в отдельные квадратные скобки.

```text
[гидроизоляция] [подземных] [резервуаров]
[гидроизоляция] для [подземных] [резервуаров]
```

**Обязательное правило пользователя:** применять отдельные квадратные скобки для каждого слова, кроме предлогов, чтобы устранить показы по семантическому соответствию. Пользователь явно подтвердил результативность этого приёма при согласовании правил. Это установленное правило настройки, а не открытый вопрос.

Не объединять слова в общие скобки и не заменять это оформление кавычками, `!` или другими операторами без отдельного указания пользователя. При контроле кампании проверять соблюдение оформления ключевых фраз; результаты показов анализировать по фактической статистике.

### Автотаргетинг

- Оставлять только «Целевые запросы».
- «Узкие», «Широкие», «Сопутствующие» и «Альтернативные» запросы добавлять в исключения / отключать соответствующие категории доступным способом.
- Проверять итоговую конфигурацию, а не только название категории в отправленном запросе.

### Упоминания брендов в автотаргетинге

| Тип кампании | Оставить | Исключить |
|---|---|---|
| Общая | Запросы без упоминаний брендов | Запросы с упоминанием своего бренда и брендов конкурентов |
| Брендовая | Запросы с упоминанием своего бренда | Запросы без упоминаний брендов и с упоминанием брендов конкурентов |

Название своего бренда, варианты написания и конкуренты берутся из данных проекта. Эти настройки относятся к автотаргетингу; порядок исключения брендовых запросов из показов по ключевым фразам (минус-фразы и другие условия) требуется уточнить отдельно. Не заявлять, что настройка автотаргетинга сама по себе ограничивает весь трафик кампании.

## Объявления — навык ad-creative

Использовать $ad-creative с профилем Яндекс Директа из нашего репозитория. На объявление — 7 заголовков, 3 текста, 8 быстрых ссылок с основными УТП в первых четырёх и уточнения с рекомендуемым наполнением 200–300 символов (каждое до 25). Каждый заголовок содержит маску группы или название услуги. Проверить все 21 пару и технические лимиты по профилю навыка; подготовка пакета не означает сохранение в кабинете.

## Контроль результата

После фактического создания проверить настройки кампании, групп, аудиторий и разметки доступным чтением. Сохранить ID объектов и параметры в тематических файлах проекта; действия с датой, объектом и явно указанной причиной — в CHANGELOG.md. Не фиксировать написание этого шаблона как создание рекламной кампании.

## Поиск — параметры, определяемые по проекту

- Конкретные кабинет, счётчики, согласованные goal_id фактических лидов и география — из ТЗ и базы знаний проекта; если их нет, запросить.
- Индивидуальная сумма недельного бюджета — из ТЗ; при отсутствии суммы применять 15 000 руб. без НДС на кампанию. Максимальный CPC не устанавливать без прямого требования ТЗ.
- Расширенный геотаргетинг, брендовые минус-фразы для показов по ключевым фразам и команда на запуск — учитывать по заданию; если нужный для операции параметр не определён, уточнить его без произвольного выбора.
- Технический способ точного подсчёта отказных и рекламных визитов — проверить при реализации; не менять согласованную логику ради доступного, но неэквивалентного фильтра.

Не подменять ценность цели отдельным ограничением средней цены конверсии. В выбранном варианте стратегии оплата идёт за клики, ограничение расходов — недельный бюджет, согласованные суммы у целевых действий — их ценности. Не назначать ценности произвольно и не принимать рекомендацию системы за согласование пользователя. Если цели или их ценности не согласованы, запросить их до настройки стратегии.

Для исключения уже полученных лидов по-прежнему использовать только цели фактического обращения. Набор целей оптимизации и набор целей исключения сверять отдельно; выбор цели оптимизации сам по себе не добавляет её в исключения.

### Аудитории и корректировки РСЯ

До создания кампании создать или проверить аудитории по [общим правилам исключений](CAMPAIGN_RULES.md#shared-exclusions):

- Не менее 2 отказных визитов из Яндекс Директа за последние 90 дней: −100%.
- Не менее 4 визитов из Яндекс Директа за последние 90 дней: −100%.
- Достижение любой одной согласованной цели фактического лида за последние 360 дней, источник любой: −100%.

Добавить также возрастные корректировки из таблицы РСЯ: младше 18 и старше 55 лет, любой пол, −100%. Если счётчик, доступ или ключевые цели для создания аудиторий неизвестны, запросить их до создания аудиторий и кампании. Использовать скользящие окна, точный подсчёт подходящих визитов и проверенные ID; не создавать дубликаты эквивалентных аудиторий.

### Параметры URL РСЯ

Применять ту же [стандартную UTM-строку](CAMPAIGN_RULES.md#url-parameters), что и на Поиске, без изменения имён, значений, макросов и разделителей. Правила операторов Поиска на ключевые слова РСЯ не переносить.

Источник пользователя: [Google Sheets «ТОП-250 минус площадок»](https://docs.google.com/spreadsheets/d/17Mios41mh1hP1P3rZdSVSv_aL_3lvf8tMN1vSC8QKQg/edit?usp=sharing), лист «ТОП-250 минус площадок», столбец A «Общий список минус площадок». Разбивку по категориям в других столбцах не добавлять повторно.

Проверенный снимок: [campaigns/RSYA_BLOCKED_PLACEMENTS.txt](campaigns/RSYA_BLOCKED_PLACEMENTS.txt). Дата чтения источника — 2026-11-25; диапазон снимка A3:A223; 221 непустое уникальное значение. Каждая строка TXT — один идентификатор площадки без заголовка. Название источника «ТОП-250» не означает, что в нём ровно 250 записей.

Перед созданием новой кампании:
1. Проверить метаданные исходной таблицы, точный лист, заголовок и текущие границы данных. Прочитать актуальный общий список; при изменении структуры сначала определить нужный столбец, не угадывать его.
2. Убрать пустые строки, заголовок и точные дубликаты; сохранить написание и регистр идентификаторов, включая приложения и SSP. Не заменять их доменами по предположению.
3. Сохранить применяемый список внутри Agent/campaigns/ конкретного проекта с датой получения и ссылкой на источник. Зафиксировать количество строк; не выдавать старый снимок за только что проверенный источник.
4. Добавить список в запрещённые площадки новой кампании. Если интерфейс или API отклоняет отдельные значения, перечислить их пользователю; не отчитываться об их применении и не отбрасывать молча.
5. Проверить сохранённые исключения чтением кампании. Фактическое изменение и используемую версию списка записать в CHANGELOG.md.

Если источник недоступен, сообщить об этом и согласовать использование последнего проверенного снимка либо запросить актуальный список. Не создавать пустой список вместо базового. Новые кампании получают актуальный проверенный список; существующие кампании из-за изменения таблицы автоматически не редактируются.

### Группы РСЯ

- Географию задавать на уровне групп по ТЗ; при отсутствии отдельного ТЗ — по согласованной желаемой географии проекта. Если она не определена, запросить.
- Ключевые слова добавлять без операторов. Поисковое оформление отдельных слов в квадратные скобки и другие поисковые ограничения здесь не применять.
- Включать автотаргетинг в Рекламной сети Яндекса. Поисковые категории запросов и исключения упоминаний брендов автоматически не переносить.
- Минус-фразы не добавлять ни на уровне групп, ни на уровне кампании; не переносить минус-фразы из Поиска. Не добавлять минус-слова к ключевым фразам.

### Объявления РСЯ — навык ad-creative

Использовать тот же $ad-creative с профилем Яндекс Директа и составом 7/3/8, требованиями к маске/услуге, совместимости и уточнениям. Данные аудитории и предложения брать из конкретной группы РСЯ.
