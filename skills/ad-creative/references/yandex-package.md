# Машинный пакет объявления Яндекс Директа

Один JSON-файл — одно объявление. Ниже только структура, а не готовые тексты или подтверждённые факты.

```json
{
  "group": "Название группы",
  "service": "Маска группы или название услуги",
  "landing_url": "https://example.com/service",
  "headlines": ["H1", "H2", "H3", "H4", "H5", "H6", "H7"],
  "texts": ["T1", "T2", "T3"],
  "sitelinks": [
    {"title": "L1", "description": "Описание", "url": "https://example.com/section"}
  ],
  "callouts_pool": ["Уточнение"]
}
```

В реальном пакете `sitelinks` содержит ровно 8 объектов. Порядок массива определяет приоритет: первые четыре — основные УТП. Заголовки и тексты — строки. `callouts_pool` — полный набор для добавления, рекомендуемое наполнение 200–300 символов; верхний предел 300, один элемент до 25, не более 50 элементов. Сумма больше 132/76 не является ошибкой этого набора: эти пределы относятся к показу на устройствах.

Необязательные `callouts_desktop` и `callouts_mobile` могут содержать примеры отображаемых комбинаций из `callouts_pool` с суммой до 132 и 76 соответственно. Они не ограничивают исходный набор, не требуются для валидации полного пакета и не гарантируют фактический показ именно этих элементов.

Примерные URL и подписи из схемы не использовать в клиентских объявлениях. Источники фактов и смысловую проверку 21 пары сохраняй в сопровождающем Markdown. JSON-валидатор не выполняет запросы к страницам или рекламным кабинетам.
